## How it works

`main.py` holds the entry as a constant, checks it against the kit's gate (UTF-8 text, 1–5 characters, not only whitespace, digits only, no leading/trailing whitespace, no newline), and writes it to `/output/entry.txt` when run with `python3 main.py`.
